## 适合什么时候用

先说明你已经有什么素材、完成到哪一步，再从对应阶段开始。不必为了使用工作流而重新制作已有素材；它负责串联另外三个技能，而不是把三个技能替代掉。

## 安装与开始使用

1. 下载并解压 ZIP。每个包只有一个与技能 ID 同名的根目录，包含 `SKILL.md`、`agents/openai.yaml` 和 `references/` 等文件。
2. 将完整技能目录放到 `$CODEX_HOME/skills`；没有设置 `CODEX_HOME` 时，放到 `~/.codex/skills`。不要只复制 `SKILL.md`。
3. 先阅读 `SKILL.md`，按说明准备角色目标、参考素材、输入要求与验收条件，再在支持该技能的 Codex 环境中使用。
4. 按说明检查结果，再用于后续制作；不要把导入成功等同于结果已经通过验收。

## 配套技能

这个包是工作流路由，不替代另外三个制作技能。使用完整流程时，请同时安装「像素角色母图」「像素角色精灵表」「像素角色骨骼对齐」，四个目录放在同一个 `skills` 父目录下。

这是技能文件包，不是独立运行的软件安装包。所需模型、运行环境及其他依赖以包内说明为准。
